# Security and Privacy on Shakers

## Introduction

At Shakers, we prioritize the security and privacy of our users' data. This document outlines our comprehensive approach to protecting your information, ensuring secure transactions, and maintaining compliance with global regulations.

## Account Security

### Authentication Methods

Shakers offers multiple secure authentication options:

- **Password Protection**
  - Minimum 12-character requirement
  - Complexity requirements (uppercase, lowercase, numbers, symbols)
  - Regular password rotation reminders
  - Secure password recovery process

- **Two-Factor Authentication (2FA)**
  - SMS verification
  - Email verification
  - Authenticator app support (Google Authenticator, Microsoft Authenticator, Authy)
  - Hardware security key support (YubiKey, Google Titan)

- **Single Sign-On (SSO)**
  - Enterprise accounts can integrate with:
    - Google Workspace
    - Microsoft Azure AD
    - Okta
    - OneLogin

### Session Management

- Sessions expire after 2 hours of inactivity
- Concurrent session notifications
- Ability to view and terminate active sessions
- IP address and device tracking

### Account Recovery

- Multi-step verification required for account recovery
- Identity verification through multiple channels
- Recovery email address and phone number requirements
- 24-hour waiting period for sensitive account changes

## Data Protection

### Personal Data Handling

Shakers implements strict controls over personal data:

- **Data Minimization**
  - We collect only essential information needed for service provision
  - Optional profile fields clearly marked
  - Regular data audit and cleanup processes

- **Data Encryption**
  - All personal data encrypted at rest (AES-256)
  - End-to-end encryption for messages between users
  - Secure file transfer with client-side encryption

- **Data Access Controls**
  - Role-based access control for all systems
  - Just-in-time access for support personnel
  - Complete audit logging of all data access
  - Multi-layered approval for sensitive data access

### Data Storage and Retention

- Data stored in SOC 2 Type II certified data centers
- Geo-redundant backups with encryption
- Data retention periods based on regulatory requirements
- Automated data deletion after retention period expiry

## Payment Security

### Transaction Protection

Shakers maintains the highest standards for financial transactions:

- **PCI DSS Compliance**
  - Level 1 PCI DSS compliance for all payment processing
  - Regular security assessments and penetration testing
  - No storage of complete credit card numbers

- **Secure Payment Processing**
  - All transactions processed through certified payment gateways
  - 3D Secure authentication for card payments
  - Advanced fraud detection systems
  - Real-time transaction monitoring

### Escrow System

- Client funds held in secure escrow accounts
- Segregated from operating accounts
- Released only upon milestone completion or mutual agreement
- Protected from company insolvency

## Communication Security

### Messaging Security

- End-to-end encryption for all direct messages
- No message content scanning for advertising purposes
- File scanning for malware before download
- Ability to delete message history

### Video Conferencing

- Encrypted video and audio streams
- Password-protected meeting rooms
- Waiting room functionality for participant screening
- No recording without explicit consent from all parties

## Security Best Practices for Users

### Account Security Recommendations

We recommend all users follow these best practices:

1. **Create Strong, Unique Passwords**
   - Use a password manager
   - Never reuse passwords across sites
   - Consider using passphrase approach

2. **Enable Two-Factor Authentication**
   - Adds crucial second layer of protection
   - Preferably use an authenticator app rather than SMS

3. **Verify Communications**
   - Be wary of unsolicited messages
   - Check email sender addresses carefully
   - Report suspicious communications

4. **Use Secure Networks**
   - Avoid public WiFi for sensitive transactions
   - Consider using a VPN for additional protection
   - Ensure home networks are properly secured

### Safe Collaboration Guidelines

For secure project collaboration:

1. **Work Within the Platform**
   - Keep communications on Shakers
   - Use our secure file transfer system
   - Process all payments through our system

2. **Control Access to Deliverables**
   - Use watermarks for draft creative work
   - Share files with appropriate permissions
   - Revoke access when collaboration ends

3. **Project Documentation**
   - Clearly document all agreements in writing
   - Save important communications
   - Use milestone approvals to document progress
