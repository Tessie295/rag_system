# Creating Effective Projects on Shakers

## Introduction

Creating a clear, comprehensive project listing is crucial for attracting the right talent and achieving successful outcomes. This guide will walk you through the process of creating projects that draw qualified proposals and set the stage for productive collaborations.

## Project Types on Shakers

Shakers supports several project types to accommodate different working arrangements:

### Fixed-Price Projects

Best for well-defined deliverables with clear scopes and timelines.

**Key Features:**
- Set total budget upfront
- Define specific milestones with payment amounts
- Payment released upon milestone completion
- Best for projects with clearly defined deliverables

**Example Use Cases:**
- Logo design
- Website development
- Content creation for a specific campaign
- Mobile app development

### Hourly Projects

Ideal for ongoing work or projects where the scope may evolve.

**Key Features:**
- Set hourly rate range
- Define weekly hour expectations
- Automatic time tracking with work verification
- Weekly billing cycle

**Example Use Cases:**
- Ongoing development or maintenance
- Long-term content creation
- Marketing campaign management
- Data analysis and reporting

### Contests

Perfect for creative projects where you want multiple concept options.

**Key Features:**
- Set prize amount(s)
- Review multiple submissions from different freelancers
- Pay only for the winning submission(s)
- Ideal for design-related projects

**Example Use Cases:**
- Logo design
- Brand identity
- Product packaging
- Website mockups

## Creating Your Project

### Step 1: Define Your Project Basics

Start with the fundamental details:

- **Project Title**: Create a clear, specific title that includes key skills (e.g., "WordPress E-commerce Site Development with WooCommerce Integration")
- **Project Category**: Select the most relevant category for proper placement in the marketplace
- **Project Type**: Choose between fixed-price, hourly, or contest

### Step 2: Write a Comprehensive Description

A detailed project description helps freelancers understand your needs and requirements:

**Essential Elements to Include:**
- **Project Overview**: Brief summary of the project and its objectives
- **Detailed Requirements**: Specific features, functionalities, or deliverables
- **Technical Specifications**: Platforms, programming languages, or tools required
- **Visual References**: Example links or attachments showing similar work
- **Timeline**: Expected project duration and key milestones
- **Budget Expectations**: Rough estimate or range for the project

**Best Practices:**
- Use bullet points for clarity
- Divide information into logical sections with headings
- Be specific about deliverables
- Clearly state what success looks like
- Mention any constraints or limitations

### Step 3: Specify Required Skills

Select relevant skills that freelancers must possess:

- Choose primary skills (must-have)
- Add secondary skills (nice-to-have)
- Specify minimum experience levels
- Consider industry-specific expertise

### Step 4: Set Budget and Timeline

Establish clear financial and temporal parameters:

**For Fixed-Price Projects:**
- Set a total budget or range
- Create milestone deliverables with individual payments
- Align payment schedule with project phases

**For Hourly Projects:**
- Set hourly rate range based on skill level required
- Specify weekly hour expectations
- Define project duration estimate

**Tips for Budget Setting:**
- Research market rates for similar projects
- Consider complexity and expertise required
- Allow flexibility for exceptional talent
- Include buffer for potential scope adjustments

### Step 5: Add Screening Questions

Custom questions help filter candidates effectively:

- Include 3-5 targeted questions
- Ask about specific experience relevant to your project
- Request approach explanations for technical problems
- Inquire about familiarity with tools or methodologies

**Example Questions:**
- "Describe your experience building e-commerce sites with similar functionality."
- "What approach would you take to optimize the site's loading speed?"
- "How would you handle mobile responsiveness for this application?"

### Step 6: Attach Supporting Files

Provide visual or technical documentation:

- Wireframes or mockups
- Brand guidelines
- Technical specifications
- Examples of similar projects
- Legacy code (if applicable)

## Tips for Attracting Top Talent

### Be Transparent About Budget

- Provide realistic budget ranges aligned with market rates
- Explain budget constraints if present
- Be upfront about payment terms and schedule

### Show Long-Term Potential

- Mention possibilities for ongoing work if applicable
- Describe future phases or related projects
- Highlight opportunities for portfolio enhancement

### Respond Quickly to Questions

- Set aside time to answer freelancer questions promptly
- Provide clarifications and additional details when requested
- Show engagement and commitment to the project

### Showcase Your Credibility

- Complete your client profile thoroughly
- Share information about your company
- Mention previous successful projects on Shakers

## Common Mistakes to Avoid

### Vague Requirements

**Problem**: Unclear expectations lead to misaligned proposals.
**Solution**: Be specific about deliverables, functionality, and acceptance criteria.

### Unrealistic Budgets

**Problem**: Below-market budgets attract inexperienced talent.
**Solution**: Research competitive rates and set appropriate ranges.

### Insufficient Technical Details

**Problem**: Generic descriptions make it difficult for specialists to evaluate fit.
**Solution**: Include specific technical requirements, platforms, and compatibility needs.

### Overlooking Intellectual Property

**Problem**: Unclear ownership terms can cause disputes.
**Solution**: Explicitly state IP transfer expectations in the project description.

## After Publishing Your Project

Once your project is live:

1. **Review Incoming Proposals**: Evaluate based on experience, approach, and budget alignment
2. **Interview Promising Candidates**: Schedule video calls to discuss details
3. **Request Portfolio Samples**: Ask for examples of similar work
4. **Check Reviews and Ratings**: Examine feedback from previous clients
5. **Provide Prompt Feedback**: Let candidates know about your decision timeline

## Project Template Examples

### Web Development Project Template

```
# WordPress E-commerce Website Development

## Project Overview
Development of a fully responsive e-commerce website using WordPress and WooCommerce for a boutique clothing retailer. The site needs to handle approximately 500 products with custom categorization and filtering options.

## Key Requirements
- Custom theme development based on provided design mockups
- WooCommerce implementation with custom product attributes
- Payment gateway integration (Stripe, PayPal)
- Shipping calculation module with real-time rates
- Customer account management
- Inventory management system
- Analytics and reporting dashboard

## Technical Specifications
- WordPress latest version
- PHP 8.0+
- Responsive design (mobile, tablet, desktop)
- SEO optimization
- Page load speed < 3 seconds
- GDPR compliance features

## Deliverables
1. Complete WordPress website with e-commerce functionality
2. Custom theme and necessary plugins
3. Admin documentation
4. Training session for content management
5. 30 days of post-launch support

## Timeline
- Expected duration: 8 weeks
- Key milestones will be established with the selected freelancer

## Budget
$5,000 - $7,000 USD
```
